# Reading Digital Signals

## Introduction
Recall our lesson on [digital signals](https://cogs-300.github.io/teaching/activities/signals), where we thought about digital signals in terms of _output_ as lights. Today, we're going to flip it around and think about digital signals from an _input_ standpoint.

As we learned in our first lecture, every intelligent system has both input and output, where output is some kind of effect on the world (like actuation) and input is sensing of the world. In the middle, there's some kind of decision-making system. 

In this activity, we're going to learn how to make our first sensing system. It is very basic. However, do not let basic be mistaken for not useful: this exact kind of sensing system runs many very important manufacturing machines today.

### Activityf
Today, we're going to follow the design process again, but from the input side. Rather than a braking system, we're going to design a car door sensing system.

Every modern car has a door sensing system. Door sensing systems are very common, from fridges to washing machines, many devices need to sense the state of a door. Usually, the sensor component is very simple, just or or more buttons. But the design may be complex. The door will also have an indicator that lets the user know the status of the door.

Work together with your group to assemble a looks-like prototype and a works-like prototype for a car door sensing system. You should be assembling a single, shared prototype.

#### 8. Stretch Goal: Implement timing
Arduino provides a function called `millis()` that lets you know how many milliseconds it has been since you started the Arduino. You can use it like this:

```cpp
int ledState; 

int now;
int last;
int difference;

void setup()
{
  pinMode(A0, INPUT);
  Serial.begin(9600);
  ledState = 0;
  
  now = 0;
  last = 0;
  difference = 0;
}

void loop()
{
  // Read the time right now
  now = millis();

  // Read the LED state
  ledState = digitalRead(A0);

  // If the button has been pressed
  // set the last time to now
  if (ledState == HIGH) {
    last = now;
  }

  // Take the difference between this reading and the last reading
  // to see how long it has been since the button was pressed
  difference = now - last;
  Serial.print("The LED reads: ");
  Serial.print(ledState);
  Serial.print(". The button was last pressed ");
  Serial.print(difference);
  Serial.println(" milliseconds ago.");

  delay(10);
}
```
