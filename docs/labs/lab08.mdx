## Lab
The 

### 1. Transitions
The first thing to figure out is how to transition between tournament sections. When does your robot know to stop line-following, and start wall-following? When does it know to start object detection? Ensure that your robot "knows" when it is in each section of the tourament.

### 2. Implement a Sweep
Using the constructed object detection arena, implement an object detection sweep with your robot. Make sure that it can figure out the angle at which an object lies from it. Sweep back and forth with the robot and have it drive towards the closest object.

### 3. Demonstrate All Angles (homework)
Show that your robot can approach the object from any possible angle, i.e., your robot can be spun around arbitrarily and still find the object.

### 4. Stay within the Arena (not homework)
You will eventually need to ensure that your robot stays within the white lines of the object detection arena. That is like combining line-following with object detection. That is not due this week, but you should probably get it figured out soon.
